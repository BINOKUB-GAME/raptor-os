Simulateur Interactif : Filtrage Noyau Packet Filter (pf)

Injectez des flux réseau sur l'interface matérielle Intel em0 pour observer en temps réel comment CENTURION / RAPTOR-OS 2.0 isole les transactions légitimes, bannit les attaquants dans <bruteforce> et verrouille ses journaux dans /raptor_blackbox.

Interface Intel em0

EN ATTENTE
ÉTAGE 02 · PARE-FEU NOYAU

Packet Filter (pf)

Filtrage synproxy et tables mémoire dynamiques.

EN ATTENTE
ÉTAGE 03 · ESPACE UTILISATEUR

Passerelle C Confinée

Parseur binaire isolé par pledge(2) et unveil(2).

EN ATTENTE
ÉTAGE 04 · INTÉGRITÉ DISQUE

/raptor_blackbox

Journaux sappnd verrouillés par securelevel=1.

EN ATTENTE

Extrait actif : /etc/pf.conf

block drop in quick on $ext_if all
block drop quick from <bruteforce>
pass in on $ext_if proto tcp from <partenaires_paiement> to port 443 synproxy state (max-src-conn-rate 40/1, overload <bruteforce> flush global)
pass in log on $ext_if proto tcp from <partenaires_paiement> to ($ext_if) port 443 keep state
# sysctl kern.securelevel=1 + chflags schg /etc/pf.conf

Tables mémoire noyau pfctl -s Tables

<partenaires_paiement>
    <bruteforce> (Dynamique)
      FLUX TEMPS RÉEL — /raptor_blackbox/audit.log (append-only)
      [INIT] Interface Intel em0 prête — Packet Filter (pf) actif — kern.securelevel=1 verrouillé.
